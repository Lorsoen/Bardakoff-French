# Banjo-Kazooie: Bardakoff French

Ce mod implémente le français PAL dans l'édition Recomp du jeu.

This mod brings PAL french in the recomp.

### Incompatibilitées / Conflicts

Ce mod ne fonctionnera probablement pas avec d'autres mods changeant les dialogues.

This mod will likely conflict with other language packs.

### Problèmes connus / Known Issues

- La grande fonte du jeu n'est pas rendue (prob avec Latin1)
- Big font does not render (Latin1 issue)

- Les effets de texte ne fonctionnent pas (pareil, Latin1)
- Textbox commands (such as shake) do not work (Same, Latin1)
